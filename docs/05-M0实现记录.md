## 3. 首关实现口径

- **工具门**：必须提交模式规则（`pattern/commit`）并补齐三个缺口，否则 `submit` 返回 4 条 `missingEvidence`；
- **观察**：ToolDock 的"观察带子"按钮派发 `pattern/inspect`；画布同步显示观察环；
- **规则**：A/B 拼出重复单元 + 变换；`pattern/setCycle` 后 `pattern/commit`；
- **修补**：构造块按 `slots [6,7,8]` 放 A/B/B（palette id 已与 token 对齐为 A/B）；
- **判定**：`validatePattern` 先查可见格冲突、再查缺口、再查修补块是否与规则一致；
- **autoplay**：`actionsFor` 生成与真实操作相同的动作序列，逐条 `dispatch`，最后 `submit`；
- **存档**：通关写 `levels[id].completed`、`completedVariants`、`stamps`、工具使用与 journal；证据另写 `evidence:local-default`；
- **调试桥**：`window.__mmf` 暴露 events/save/snapshot/lastError/attemptSubmit（仅 DEV / webdriver）。

## 4. 与方案文档的偏差（需在 M1 对齐或保留）

| # | 文档口径 | M0 实现 | 处理建议 |
|---|---|---|---|
| 1 | 证据按 2 秒/阶段批量 append | 每条草稿立即 append | M0 优先保证链路与事件不丢；M1 接入批量/节流 |
| 2 | `LevelDetail.tools` 含 6 种工具 | 只有 pattern/construct 有 UI，其余占位 | M1 随模板补齐 |
| 3 | 模板 6 个 | 只有 pattern 实现；其余 schema 用 `z.unknown()` 占位 | M1–M2 逐个替换 |
| 4 | 20 关 | 只有首关（`SHIPPED_LEVEL_IDS` = 1） | M1 扩到 6、M2 扩到 20 |
| 5 | 双语 | 中文界面 + 中文内容；`ensureMessages('en')` 为空实现 | v0.9 接英文补丁 |
| 6 | 完成时记录 duration/material | `durationMs` 传 0；materials 为空 | 接入运行时长与产物摘要 |
| 7 | 简洁/迁移/论证印章 | 首关只发 constraint（变体审计发 transfer） | 随变体 UI 与 argue 模板补齐 |
| 8 | 三端打包 | 只有 Web 产物；无 Tauri/Capacitor | v0.9 接壳 |
