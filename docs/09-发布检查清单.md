- [ ] 静态托管部署与回滚路径（待运维）；

## 6. 阻断规则

以下任一未满足，不发布 v1.0：

1. 用户测试出现阻断级问题；
2. `pnpm verify` / `pnpm e2e` / `pnpm e2e:dist` 任一失败（三条都要跑：dev e2e 测不到生产注入）；
3. 原生壳未构建但对外宣称有 EXE/APK；
4. 报告中出现正确率、刷题量或排名；
5. 真实姓名/学校/位置进入证据包；
6. 首屏 gzip 超过 85 KB 或 dist 超过 4 MB（英文兜底表已接近预算，加文案前先量体积）。
