# 用户测试协议（v1.0 发布前）

> 本协议供家长/教师/研究者执行；代理不能替代真人测试，也不能预填观察结果。测试结束后把原始记录放回本仓库的 `user-testing/` 目录（建议不提交含个人信息的原始表）。

## 1. 目标

验证三件事，而不是"孩子喜不喜欢"：

1. 孩子能否在无人讲解的情况下理解工具与任务；
2. 卡住时是"结构没想清"还是"界面看不懂"；
3. 家长/教师能否读懂证据报告，并据此说出孩子的一个思维特点。

## 2. 参与者

- 每个学段至少 2 人：K（5–6 岁）、G1–3、G4–6、G7–9、G10–12；
- 首次接触本产品；同一学段内尽量一男一女；
- 家长或教师在场但不提示，除非孩子连续 2 分钟无操作。

## 3. 知情同意（逐条读给监护人）

- 本测试记录**操作与口头解释**，不录脸、不录真实姓名、不收集位置与学校；
- 数据只用于改进产品，保存在本机，不上传；
- 孩子可随时停止，不需要理由；
- 报告中的昵称由孩子自选，可随时更改。

## 4. 测试流程（约 30 分钟）

1. **5 分钟**：自由探索首页与星图，不讲解；
2. **15 分钟**：按学段选 2 关（见下表），观察并记录；
3. **5 分钟**：打开日志/徽章，问"哪一步你改得最多"；
4. **5 分钟**：家长/教师看报告，复述一个发现；
5. 结束：孩子自选昵称，记录设备与浏览器。

| 学段 | 推荐关卡 | 观察重点 |
|---|---|---|
| K | k-structure-pattern-path、k-modeling-share | 是否先观察再动手；分点心时是否先数总数 |
| G1–3 | g13-algorithm-route、g13-data-weather | 失败后是否改结构；统计条是否与采集一致 |
| G4–6 | g46-algorithm-payment、g46-modeling-queue | 是否用反例；调参是否一次只改一个 |
| G7–9 | g79-structure-network、g79-data-sampling | 是否检查连通；是否理解样本与区间 |
| G10–12 | g1012-data-inference、g1012-algorithm-frontier | 是否用区间判断；能否说清贪心为何失效 |

## 5. 观察记录（每关一行）

| 字段 | 说明 |
|---|---|
| 关卡 | id |
| 完成 | 是 / 否 / 中途停止 |
| 用时 | 分钟 |
| 首次操作 | 观察 / 直接试 / 求助 |
| 卡点 | 结构 / 界面 / 读题 / 工具 |
| 求助次数 | 0 / 1 / 2+ |
| 关键原话 | 逐字记录，不润色 |
| 是否重试 | 否 / 改结构 / 重复提交 |

## 6. 成功标准（v1.0）

- 至少 8/10 名参与者能在 2 次求助内完成所选 2 关；
- 至少 7/10 能说出"我改了什么、为什么"；
- 至少 6/10 的家长/教师能仅凭报告说出一个具体思维特点；
- 无阻断级问题：无法加载、存档丢失、报告打不开、切语言后关键按钮消失。

未达标的项进入发布阻断清单，不因"整体不错"放行。

## 7. 隐私与留存

- 原始记录只写昵称/编号，不写真实姓名、学校、精确地址；
- 截图前先关闭报告中的昵称或改为编号；
- 测试记录保留 90 天后删除；
- 对外引用只使用汇总数字与匿名原话。
