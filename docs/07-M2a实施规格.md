### 1.3 四维画像（M2a 口径）

| 维度 | 证据 | 三档 |
|---|---|---|
| 结构 | 观察事件覆盖的关卡数；结构主线关卡完成数；transfer 印章数 | 0 无 / 1 有观察 / 2 完成结构关 / 3 有迁移 |
| 规则 | 规则关完成；失败→修订过的关卡数；程序运行事件 | 0 无 / 1 完成规则关 / 2 有修订 / 3 迁移通过 |
| 模型 | 模拟/实验关完成；knob/probe 事件数；两种子通过 | 0 无 / 1 调过参数 / 2 指标达标 / 3 换种子仍稳 |
| 边界 | 有效反例产物事件数；支付关完成；transfer 印章 | 0 无 / 1 完成支付 / 2 找到反例 / 3 反例+迁移 |

总结句用中文，例如"你会先观察再动手，也能把规则用到转过方向的地图上。"不要写分数。

### 1.4 徽章规则（按现有 6 关可达成）

| id | 条件 | progress |
|---|---|---|
| observer | 至少在 2 个关卡产生 observe 事件 | 关卡数 / 2 |
| pattern-spotter | k-structure-pattern-path 完成 | 0/1 |
| rule-designer | g13-algorithm-route 完成 | 0/1 |
| builder | g46-algorithm-payment 完成 | 0/1 |
| modeler | g79-modeling-dispatch 完成 | 0/1 |
| experimenter | g1012-modeling-winrate 完成 | 0/1 |
| boundary-explorer | 至少 1 个 `artifact.kind === "counterexample"` 且 outcome=pass 的事件 | 0/1 |
| reviser | 至少 1 个完成的关卡 `lastOutcome.revisionCount > 0` | 0/1 |
| transferer | 至少 2 个完成关卡带 transfer 印章 | n/2 |

`earned = save.badges[id] 存在 || current >= target`（refreshBadges 会把前者落盘）。

### 1.5 推荐

按顺序找第一个未完成关卡，给 title + reason（如"还没试过用数据说话"）；全部完成则推荐"再做一次"或"换一种做法"。最多 3 条。

### 1.6 测试

每个文件至少覆盖：空档、单关完成、全 6 关完成、badge 达成/未达成、report 隐私文案、trail 排序与 limit。

## 3. 叙事 UI（narrative-builder）

写以下文件（只写这些）：

1. `apps/site/src/components/AdultGate.vue` — 长按 3 秒解锁，emit("unlock")；data-testid="adult-gate"、"adult-hold"；松手/离开取消；键盘可长按 Space/Enter。
2. `apps/site/src/components/TrailList.vue` — props `items: TrailItem[]`；竖向时间线，显示时间、关卡、阶段、工具、失败类；空态"还没有思维轨迹"。
3. `apps/site/src/components/BadgeGrid.vue` — props `badges: BadgeView[]`；已得/未得两种卡片，显示 criteria 与 progress；不弹全屏庆祝。
4. `apps/site/src/views/JournalView.vue` — 调 `useProgress()`：`init()`、`loadEvidence(300)`；用 `buildTrail(save, evidence, LEVEL_SUMMARIES, 80)` 渲染 `TrailList`；上方显示 journal 条目（最近 20 条），每条显示关卡标题、日期、印章、工具、失败类、修订数；空态。
5. `apps/site/src/views/BadgesView.vue` — 调 `evaluateBadges` 渲染 `BadgeGrid`；页面说明"徽章由证据授予，不按通关次数"。
6. `apps/site/src/views/ReportView.vue` — 先渲染 `AdultGate`；解锁后 `buildReport`，一页式报告：工具使用、关卡表、四维三档描述、下一步建议、本周时长/日志数；`window.print()` 打印；导出 `toReportPack` 用 `platform.files.download("mmf-report.json","application/json", JSON.stringify(pack))`；data-testid="report-view"、"report-print"、"report-export"。

Props/数据来源：`LEVEL_SUMMARIES` 从 `@mmf/content`，`useProgress` 由 Lead 提供；不要改 router/App/Home/进度包/证据包。

UI 用 Tailwind token（bg-card/text-ink/border-grid 等），中文文案可字面量；关键按钮 ≥44px；打印样式用 `print:` 前缀或局内样式。
